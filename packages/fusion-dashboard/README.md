# fusion-dashboard (Trust Fusion)

Fuses Layer 1 (data trust) and Layer 2 (model trust) signals into a single
per-device trust score, with alert routing and a reporting dashboard.

Planned components (Week 7):
- Trust score fusion logic
- Alert routing (severity tiers)
- Reporting dashboard

Importable as `trustguard_fusion` (Python 3.10+).
